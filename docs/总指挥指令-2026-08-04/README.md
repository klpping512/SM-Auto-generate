## 背景速记（为什么做这些）

- **匹配失败 + 视频质量差 是同一个根**：系统无 AI 文生视频，成片是 FFmpeg 拼真实素材；匹配不足会触发自适应降级出片，降级片就是"质量差"。修匹配同时治两病。
- **两侧素材性质不同**：热点素材每 3 天批次抓取、切几秒 hook（时效/覆盖问题，打标无效）；Buffalo 自有素材静态、靠人工打标（可打标修）。诊断必须区分。
- 昨日已升级 MIMO V2.5 PRO 等模型——只改善"大脑"（脚本/打标/打分），改善不了"画面本身"。
