# SA-LogiFlow 7.5 素材与视频成片功能摘要

> 更新时间：2026-07-05

## 目标闭环

`素材入库 → MiMo v2.5 分镜 → 素材匹配 → MiMo TTS → FFmpeg 合成 → 编辑器预览 → 审核 → 抖音发布`

## 已实现

### 素材库

- 数据库是素材唯一真相源，支持管理员页面上传和 `static/assets/import/` 目录导入。
- 图片通过 Pillow 验证，视频通过 ffprobe 验证；按 SHA-256 去重。
- 素材记录包含分类、尺寸、时长、缩略图、来源、状态和创建人。
- 页面支持筛选、预览、编辑、删除或引用后停用；“使用此素材”只关联数据库 ID。

### 抖音结构化脚本与 MP4

- 内容生成主模型为 `mimo-v2.5`，TTS 使用 `mimo-v2.5-tts`。
- 抖音结果包含约 30 秒、4–6 场景的画面、口播、字幕和受控素材 ID。
- 编辑器支持逐场景编辑、换素材和选择冰糖、茉莉、苏打或白桦音色。
- 后台任务逐场景生成 WAV，FFmpeg 输出 1080×1920 H.264/AAC MP4。
- 素材原声降至约 15% 后与 TTS 混合；无素材场景使用品牌信息卡兜底。
- 成片作为视频附件进入审核和抖音 RPA；没有 MP4 时禁止抖音入队。
- 配置页显示 FFmpeg、ffprobe 和 MiMo Key 就绪状态。

### 小红书预览

- 自动轮播图按真实 3:4 比例双列展示。
- 点击打开全屏 Lightbox，支持翻页、页码、遮罩和 Escape 关闭。
- 图片 URL 来自受控附件并经过转义，不使用动态内联事件字符串。

## 对抗性边界

- MiMo v2.5 是全模态理解、文本输出模型，不直接生成图片；小红书 PNG 由品牌模板确定性渲染。
- 目录导入只扫描受控路径，API 不接受任意本机路径。
- MiMo Key 只进入 `.env` 或运行环境，不进入源码、响应、日志和知识库。
- 缺少 FFmpeg/ffprobe 或 MiMo Key 时禁用视频渲染，不返回假成功。
- 不自动添加来源不明的背景音乐。

## 部署条件与验收

1. `.env` 配置 `MIMO_API_KEY`。
2. PATH 中安装 `ffmpeg` 和 `ffprobe`。
3. 重启服务，配置页三项均显示就绪后执行真实 MP4 验收。

自动化测试覆盖素材校验、去重、CRUD、分镜约束、MiMo WAV 解码、缺失依赖和平台入队门禁。浏览器已验证素材库、小红书 Lightbox、抖音分镜区和依赖缺失禁用状态。
