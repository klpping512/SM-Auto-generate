# 热点事件虚拟素材与成片时长预算设计

## 背景

当前热点视频以一条完整母片进入内容资产库。事件识别结果存储在附属表中，但匹配和“使用”仍可能引用母片，因此 120 秒视频存在被整段带入成片的风险；热点分类也只能看到一个母片，无法按事件选择素材。

## 目标

1. 将一条热点视频按事件拆成可独立匹配、独立使用的虚拟素材条目。
2. 任何成片编排只接受事件片段或 Buffalo 原有素材，不接受热点母片作为普通候选。
3. 在渲染前后都校验片段时间范围和总时长预算，杜绝整段母片误用。
4. 在不复制视频文件的前提下复用同一母片，控制本地和服务器存储成本。

## 非目标

- 不在本次工作中重新设计热点抓取或 MiMo 质检流程。
- 不把每个事件片段复制成新的视频文件；仅在需要导出时临时裁剪。
- 不改变 Buffalo 原有素材的人工管理方式。

## 核心模型

### 母片

母片仍保存在 `assets` 表，标记为 `library_origin=hotspot_source`，只用于原始证据、重新分析和事件重建。母片不进入默认匹配候选，也不显示“直接使用”按钮。

### 虚拟事件素材

事件片段在 `hotspot_event_clips` 中增加可匹配字段：

- `virtual_asset_id`：稳定的虚拟素材标识；
- `asset_id`：母片 ID；
- `start_ms`、`end_ms`：必须落在母片时长内；
- `duration_ms`：`end_ms - start_ms`；
- `thumbnail_path`：从片段中抽取的代表帧；
- `title_zh`、`title_en`、`source_label`、`hotspot_id`；
- `library_origin=hotspot_event`；
- `review_status`、`confidence`。

虚拟素材的显示标题采用双语事件标题，并附时间范围，例如：

`开普敦｜Transnet 土地事件｜00:06–00:12`

母片仍显示在“热点原始素材”折叠区域，不参与默认匹配。

## 匹配和编排

匹配器返回统一的 `clip_ref`：

```json
{
  "library_origin": "hotspot_event",
  "asset_id": 298,
  "event_clip_id": 2,
  "start_ms": 6000,
  "end_ms": 12000,
  "duration_ms": 6000
}
```

热点事件和 Buffalo 原有素材继续分开排名，各自最多 Top 3。成片时间线保存 `clip_ref`，不只保存母片 `asset_id`。

## 平台时长预算

默认预算：

| 平台 | 总时长 |
|---|---:|
| 抖音 | 30 秒 |
| 小红书 | 45 秒 |
| YouTube | 60 秒 |
| 公众号视频 | 90 秒 |

允许用户在项目级覆盖，但必须在 15–180 秒范围内。编排器按时间线顺序累计片段时长：

1. 若加入后不超过预算，保留完整片段；
2. 若加入后超过预算，裁剪当前片段到剩余预算；
3. 剩余预算不足 1 秒时停止添加；
4. 不允许通过引用母片绕过预算校验。

默认建议热点事件占 30%，Buffalo 原有素材占 70%，但两者都受同一总预算约束。

## 渲染策略

- FFmpeg 使用 `-ss`、`-t`/`-to` 对母片做临时裁剪；
- 片段裁剪到临时目录，渲染完成后自动清理；
- 事件片段导出失败时标记该片段，不阻塞其他素材；
- 最终渲染前执行硬校验：时间范围、文件存在、时长、总时长、片段来源；
- 输出元数据记录实际使用的事件片段和裁剪时长，便于追溯。

## 前端交互

热点素材库分三层：

1. 热点事件素材：可直接匹配和使用的事件片段卡；
2. 热点原始母片：折叠展示，仅支持查看原文、重新分析、重新切片；
3. Buffalo 原有素材：现有素材库。

事件卡显示：缩略图、双语标题、来源、事件时间、片段时长、权利状态、审核状态和“加入成片”。

视频工作台显示当前时间预算、已用时长、剩余时长，以及每个时间线片段的来源和实际时间范围。

## 异常和降级

- 事件时间范围非法：拒绝写入并记录错误；
- 片段缩略图生成失败：保留事件条目，显示母片占位图；
- 片段置信度低：显示“待复核”，仍允许人工加入但不自动加入；
- 母片缺失：事件标记不可用，不删除事件元数据；
- 预算未配置：使用目标平台默认值；
- 重复事件：以 `asset_id + start_ms + end_ms + normalized_title` 去重。

## 验收标准

1. 120 秒热点母片不出现在默认热点匹配候选中。
2. 一条母片至少能展示多个独立事件卡，每张卡有独立时间范围和标题。
3. 点击“加入成片”写入的是事件引用，不是整条母片。
4. 30 秒预算下，时间线最终时长不超过 30 秒；最后片段可被裁剪。
5. 渲染结果可以反查每个热点片段对应的母片和时间段。
6. 事件片段不产生额外长期视频副本。
7. 全部现有测试保持通过，并新增母片隔离、预算裁剪、FFmpeg 片段引用测试。
