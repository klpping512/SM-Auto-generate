# 热点选题工作台与内容资产信息架构重构设计

## 1. 背景与目标

当前“内容资产”同时承担本地素材管理、灵感链接、桌面导入、素材分析、可信源配置、南非热点抓取、品牌证据和样本生成。功能本身存在，但职责混杂，导致页面按钮堆叠、操作顺序不清楚，用户也无法理解“系统从哪里抓热点、抓到了什么、下一步该做什么”。

本次重构不增加复杂 Agent 或新的内容生成方向，只重新建立清晰的信息架构和可解释的操作链路：

1. “内容资产”只管理图片、视频和外部灵感链接。
2. 新增独立一级页面“热点选题”。
3. 热点工作流固定为“抓取 → 选择 → 核验证据 → 检查素材 → 生成样本”。
4. 页面直接解释可信源、筛选规则、版权边界和每次抓取结果。
5. 每个页面最多突出一个主操作，低频管理功能渐进展开。

## 2. 方案比较与决策

### 方案 A：继续留在内容资产页，通过按钮分组整理

改动最小，但“素材管理”和“热点选题”仍是两种完全不同的工作，未来增加来源、证据或样本状态后会再次拥挤，因此不采用。

### 方案 B：在内容资产页打开侧边栏或大型弹窗

能缓解顶部拥挤，但四步流程被困在临时容器中，刷新恢复、深链接和历史样本都不自然，因此不采用。

### 方案 C：独立“热点选题”页面

职责最清楚，可展示来源健康度、采集规则和完整生成链路，也能让内容资产页恢复为单纯素材库。用户已确认采用此方案。

## 3. 全局导航调整

左侧导航调整为：

```text
核心
  AI 对话
  热点选题
  内容编辑器
  发布队列

分析
  经营驾驶舱
  发布日历

资源
  内容资产
  企业知识库
  Prompt 模板
```

“热点选题”使用独立页面 `/hotspots.html`，页面 ID 为 `hotspots`。它属于内容生产入口而非资产管理工具，所以放在“核心”分组。“内容资产”移动到“资源”分组，但 URL 保持 `/assets.html`，不破坏已有链接。

## 4. 内容资产页重构

### 4.1 页面职责

内容资产页只回答三个问题：

- 现在有哪些可用于成片的本地图片和视频？
- 如何接入、上传和整理素材？
- 哪些外部链接只是灵感，尚未获得商用授权？

### 4.2 页面结构

页头只保留两个可见操作：

- 主操作：`上传素材`
- 次操作：`接入桌面素材`

页头下方使用两个标签页：

- `本地素材`
- `灵感链接`

本地素材页的批量分析、扫描项目导入目录放入 `更多操作` 菜单。视频精准匹配不再出现在素材页头，只从对应视频项目的问题处理入口进入。

下列入口全部从内容资产页移除：

- 南非热点
- 品牌证据
- 添加可信源
- 立即抓取
- 生成三份样本

素材镜头标签继续使用独立的“素材详情”弹窗，不再复用名为 `hotspotModal` 的容器。

## 5. 热点选题页设计

### 5.1 页面头部

标题：`热点选题`

说明：`从可信南非来源发现内容机会，用同一份证据生成视频、图文和公众号样本。`

操作层级：

- 主操作：`抓取最新热点`
- 次操作：`信源管理`
- 文本入口：`系统如何采集？`

页面头部不展示品牌证据、模型配置或素材管理按钮。

### 5.2 抓取状态摘要

主按钮下方显示一条可读状态带：

```text
上次抓取：今天 10:26
信源状态：4/5 正常
本次结果：新增 6，更新 2
```

部分失败时使用“部分来源失败”文字和警示图标，不只依赖颜色。点击后展开逐源结果：来源名称、成功/失败、读取条数、失败原因和重试入口。开放许可配图失败单独显示为“可选配图失败”，不得把事实来源标成失败。

### 5.3 主体布局

桌面端采用左右主从布局：

- 左侧约 38%：热点列表
- 右侧约 62%：当前热点工作区

小于 1100px 时改为上下布局，不出现横向滚动。

#### 左侧热点列表

顶部提供三个轻量筛选：

- 搜索标题或摘要
- 来源
- 时间：24 小时 / 7 天 / 全部

每张热点卡只显示：标题、来源、发布时间、两行摘要和状态。点击整张卡完成选择，不在每张卡上堆多个按钮。

#### 右侧四步工作区

固定展示四步进度：

```text
1 选择热点 → 2 核验证据 → 3 检查素材 → 4 生成样本
```

同一时间只突出当前步骤的一个主操作。

## 6. 四步工作流

### 步骤 1：选择热点

显示标题、发布机构、发布时间、抓取时间、摘要和“查看官方原文”。用户确认该热点与 Buffalo 内容方向有关后进入下一步。

### 步骤 2：核验证据

事实证据与品牌证据分成两个卡片：

- 事实证据：系统从官方原文提取的 claim、原文 URL、发布机构和摘录。
- 品牌证据：已经人工确认且允许公开引用的 Buffalo claim。

没有品牌证据时明确提示：`仍可生成不含品牌能力承诺的内部样本`。新增和确认品牌证据在本步骤的抽屉中完成，不跳回内容资产页。

### 步骤 3：检查素材

按视频分镜展示本地镜头 Top 3，默认只显示最佳候选和匹配依据，可展开更换。每个候选显示：素材名称、真实起止时间、场景/动作标签、匹配分和低分原因。

没有合适素材时显示“缺少什么素材”，允许继续生成带固定水印的内部预览，但不能进入发布队列。

### 步骤 4：生成样本

主操作为 `生成三份内部样本`。生成后在同一工作区使用三个标签展示：

- 视频：5 个分镜、素材片段、旁白、字幕和本地 MP4 预览状态
- 图文：6 页结构
- 公众号：800–1200 字正文和事实来源

顶部持续显示 `内部测试，不可发布`。输出目录、claim ID、模型调用次数和质量问题放入“技术详情”，默认折叠，避免干扰普通用户。

## 7. “系统如何采集”说明

点击“系统如何采集？”打开说明抽屉，使用自然语言解释：

1. 系统只读取最多 5 个管理员启用的 HTTPS RSS/Atom 来源。
2. 默认官方源为 SAnews、SARS、南非交通部、南非政府和南非储备银行。
3. 仅保留标题或摘要中命中南非、物流、港口、海关、货运、仓储等关键词的内容。
4. 系统访问文章原始域名，保存标题、摘要、发布者、时间、原文链接、抓取时间和内容哈希。
5. IOL 只用于发现线索，关键事实需要回查官方或第二独立来源。
6. 新闻图片、YouTube、TikTok 等版权不明确的媒体不会自动下载；只有自有素材或许可明确的媒体能进入成片。
7. 抓取不调用文本大模型。模型只在后续规划或审查阶段按需调用，并受任务预算限制。

说明抽屉同时展示五个来源的启用状态和最近一次抓取健康度，但“编辑 URL、启停来源”等管理员操作放在单独的“信源管理”抽屉。

## 8. 后端与数据边界

优先复用现有接口和数据：

- `GET /api/hotspots`
- `POST /api/hotspots/fetch`
- `GET/POST/PUT /api/hotspot-sources`
- `GET/POST/PUT /api/brand-evidence`
- `POST /api/hotspots/{id}/evidence-package`
- `POST /api/evidence-packages/{id}/sample-bundle`

为了让页面刷新后仍能解释最近一次抓取，需要新增最小持久状态：

- `hotspot_fetch_runs`：开始时间、完成时间、整体状态、结果 JSON、触发人。
- `GET /api/hotspots/fetch-status`：返回最近一次抓取汇总和逐源健康度。
- `GET /api/hotspots/{id}`：返回单条热点详情。
- `GET /api/hotspots/{id}/sample-bundles`：恢复该热点最近生成的样本。

抓取算法、五个默认源、事实/品牌证据结构、模型预算和发布门禁保持不变。本次不引入向量数据库、自动 Agent 循环或新的远程模型依赖。

## 9. 状态与错误处理

- 抓取中：主按钮禁用并显示“正在读取 5 个来源”，页面保留已有热点列表。
- 全部成功：显示新增、更新、跳过数量。
- 部分成功：保留成功结果，并显示失败来源和可执行的重试建议。
- 全部失败：不清空旧热点；明确说明旧内容不是“刚刚抓到”的结果。
- 证据不足：允许生成去承诺的内部样本，不伪造 Buffalo 能力。
- 素材不足：列出缺口并只允许内部预览。
- 生成失败：保留事实核验和素材选择状态，允许从当前步骤重试。
- 页面刷新：恢复最近选中的热点、证据包和样本，不强制重新抓取。

## 10. 视觉与交互规则

- 延续现有 Buffalo 米白、黑色和金色设计系统，不新建另一套视觉语言。
- 单个页面区域最多一个金色主按钮；次操作使用描边按钮，管理项使用文字入口或更多菜单。
- 不使用 Emoji 作为图标，全部使用现有内联 SVG。
- 点击目标至少 44px；焦点态清晰；状态不能只靠颜色表达。
- 主体不出现嵌套横向滚动；桌面和窄屏均允许纵向阅读。
- 技术字段默认折叠，普通用户先看到“发生了什么、下一步做什么”。

## 11. 测试与验收

### 自动化测试

- 导航出现独立“热点选题”，内容资产移动到资源分组。
- 内容资产页不再包含热点、品牌证据、可信源和抓取入口。
- 热点页存在唯一主抓取按钮、来源状态、四步工作流和采集规则说明。
- 抓取任务持久化，刷新后能读取最近汇总和逐源健康度。
- 单源失败不影响其他来源，配图失败不误伤事实源。
- 没有品牌证据时仍只生成无承诺内部样本。
- 1100px 以下页面不产生横向滚动。
- 所有内联 JavaScript 通过语法检查。

### 浏览器验收

1. 管理员进入“热点选题”，无需说明即可找到“抓取最新热点”。
2. 点击“系统如何采集？”能回答来源、关键词、保存内容和版权边界。
3. 抓取后能看懂成功数量和失败来源。
4. 选择一条热点后，只按四步顺序操作即可生成三种样本。
5. 回到“内容资产”时，页面只剩素材和灵感相关操作，页头不拥挤。
6. 1440px、1280px 和窄屏布局均无横向滚动或标题塌缩。

## 12. 不在本次范围

- 不自动抓取或下载 IOL、YouTube、TikTok 的受限媒体。
- 不增加第六个同时启用的可信源。
- 不自动把内部预览转成可发布内容。
- 不重新设计 AI 对话、内容编辑器或发布队列。
- 不解决与热点工作台无关的 Twitter 发布适配器问题。
