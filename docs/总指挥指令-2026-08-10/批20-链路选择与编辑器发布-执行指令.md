## 〇、总体

本批两件事：**A) 显式链路选择 `chain_mode`**（mix3=热点+za_stock+自有 / hotspot_owned=现状默认 / owned_only=纯自有）；**B) 恢复编辑器发布链路**（视频成功态→内容编辑器→自动文案+标签→确认→发布队列）。

**核心事实（已核实，供你信任）**：
- `plan_followup_scenes`（hotspot_video_planner.py:750）**批13 已有 za_stock 补充层**（`ZA_STOCK_SOURCE="za_stock_license"`，仅在本类缺口 `gap` 或自有不足 `len(buffalo)<owned_limit` 时才补位）。这就是"视频全自有素材"的根因——不是没接 za_stock，是**它只在缺口时才进片**。mix3 只需把"强制 ≥1"加进去。

```js
  // 1) 话题核心词：取标题"｜"前主题，按2字以上片段取前2个
  const subject = title.split('｜')[0].trim();
  (subject.match(/[一-龥A-Za-z]{2,}/g) || []).slice(0, 2).forEach(add);
  // 2) 物流节点：brief.logistics_nodes 前2个
  (Array.isArray(brief.logistics_nodes) ? brief.logistics_nodes : []).slice(0, 2).forEach(add);
  // 3) 链路标签
  if (chainMode === 'mix3') add('南非素材');
  if (chainMode && chainMode !== 'owned_only') add('热点追踪');
  // 4) 固定组合
  ['南非物流', '跨境电商', '卖家出海'].forEach(add);
  return tags.slice(0, 8);
}
```

> 若 `project.source_snapshot` 经接口已是解析对象，`JSON.parse` 分支不会触发（用 `typeof === 'string'` 守卫，安全）。
