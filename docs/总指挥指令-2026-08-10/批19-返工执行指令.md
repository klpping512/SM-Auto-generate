### P2-2 重写 `_align_cues_to_silence`

**删除**现有死代码实现（`non_silent_intervals`、`adjusted_end`、循环内 `available_start=s_end` 均未生效）。**重写为**"语音时间轴映射"：

```python
def _align_cues_to_silence(parts, total_duration, silence_points, tolerance=0.12):
    # 1) 由静音段求语音段（[0, total_duration] 补集）
    speech = []
    cursor = 0.0
    for start, end in sorted(silence_points, key=lambda x: x[0]):
        if start > cursor + tolerance:
            speech.append((cursor, min(start, total_duration)))
        cursor = max(cursor, end)
    if cursor < total_duration - tolerance:
        speech.append((cursor, total_duration))
    if not speech:
        return build_subtitle_cues(" ".join(parts), total_duration)  # fallback 旧逻辑
    speech_total = sum(e - s for s, e in speech)

    # 2) 字符占比边界 (k=0..N) → 语音秒数 → 真实时间戳
    total_chars = sum(max(1, len(p)) for p in parts) or 1
    cum = 0.0
    boundaries_sec = [0.0]
    for p in parts[:-1]:
        cum += max(1, len(p))
        boundaries_sec.append(speech_total * cum / total_chars)

    def sec_to_real(sec):
        # 把"语音秒数"映射回含静音的真实时间轴
        for s, e in speech:
            span = e - s
            if sec <= span:
                return s + sec
            sec -= span
        return speech[-1][1]

    cues = []
    for i, part in enumerate(parts):
        start = sec_to_real(boundaries_sec[i])
        end = sec_to_real(boundaries_sec[i + 1]) if i + 1 < len(parts) else speech[-1][1]
        cues.append({
            "start": round(max(start, 0.0), 3),
            "end": round(min(max(end, start + 0.05), total_duration), 3),
            "text": part,
        })
    return cues
```

**要点**：所有 cue 边界都落在语音段内（不跨静音），末条 end=最后语音段终点；单句/单语音段时退化为整段。保证 end>start、单调。

### P3-2 重写端点

```python
@router.post("/api/video-projects/{project_id}/enqueue")
async def enqueue_video_project(
    project_id: str,                       # UUID，不是 int
    req: VideoEnqueueRequest,
    user=Depends(get_current_user),
):
    project = db.get_video_project(project_id, created_by=user["id"])
    if not project:
        raise HTTPException(404, "Project not found")
    job = db.get_video_generation_job(project.get("active_job_id"))
    if not job or job.get("status") != "succeeded" or not job.get("output_path"):
        raise HTTPException(400, "成片尚未就绪，无法入队")
    platforms = req.platforms or [project.get("platform", "douyin")]
    added = []
    for platform in platforms:
        target_ids = req.account_targets.get(str(platform)) or [None]
        for target_id in target_ids:
            if target_id is not None:
                account = db.get_account(target_id)
                if not account or account.get("owner_id") != user["id"]:
                    raise HTTPException(403, "不能操作其他用户的账号")
                if account.get("platform") != str(platform):
                    raise HTTPException(400, "目标账号与发布平台不匹配")
            queue_id = db.add_to_queue(
                title=req.title or project.get("title") or "",
                body="", platform=str(platform),
                scheduled_at=req.scheduled_at, status="queued",
                created_by=user["id"],
                attachments=[{"type": "video", "path": job["output_path"]}],
                target_account_id=target_id,
            )
            added.append(queue_id)
    db.add_audit_log(user["id"], user["username"], "enqueue_video_project",
                     target=project_id, detail=json.dumps({"queue_ids": added}))
    return {"status": "queued", "queue_ids": added, "message": f"已入队 {len(added)} 条"}
```

**要点**：
- `project_id: str`（UUID）。
- job 从 `video_generation_jobs` 取，`output_path` 在 job 上。
- 写 **`queue`** 表（`db.add_to_queue`），`status="queued"`，`scheduled_at` 为空=立即（`get_scheduled_items` 只取 `scheduled_at<=now` 且 status=queued 的，故立即发布传 now 或留空需在 add_to_queue 里给默认 now——**确认 add_to_queue 把 None scheduled_at 落库为 NULL 时 get_scheduled_items 不会抓**：见 P3-3）。
- 账号校验内联（不引 app 的 `_account_for_user`，避免循环导入）。

### P3-3 scheduled_at 语义（重要）

`get_scheduled_items`（database.py）要求 `status='queued' AND scheduled_at IS NOT NULL AND scheduled_at <= now`。因此**立即发布必须把 scheduled_at 填成当前时间**，不能传 None。在端点里：
```python
from datetime import datetime
now_str = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
scheduled_at = req.scheduled_at or now_str
```
并把这个值传给 `db.add_to_queue(scheduled_at=scheduled_at, ...)`。
