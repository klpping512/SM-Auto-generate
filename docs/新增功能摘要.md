## 一、素材库搭建

### 需求
搭建视频/图片素材库，支持 buffalo 真实素材（海外仓演示视频等），供内容创作时调用。

### 实现方案

**1. 目录结构**
```
static/
  assets/
    videos/
      warehouse/
        overseas-warehouse-tour.mp4      # 海外仓全景
        warehouse-operation.mp4          # 海外仓环节展示
        sorting-center.mp4               # 分拣中心展示
      delivery/
        last-mile-delivery.mp4           # 末端配送
      customs/
        customs-clearance.mp4            # 清关流程
    images/
      warehouse/
        warehouse-exterior.jpg
        warehouse-interior.jpg
        sorting-machine.jpg
      delivery/
        delivery-truck.jpg
        delivery-team.jpg
      logo/
        buffalo-logo.png
        buffalo-logo-white.png
```

**2. 素材库 API**
```python
# app.py
@app.get("/api/assets")
async def list_assets(type: str = None, category: str = None):
    """列出素材库内容"""
    # 扫描 static/assets/ 目录
    # 返回 [{name, path, type, category, size, duration(视频)}]
```

**3. 素材库页面**（static/assets.html 改造）
- 按类型筛选：视频 / 图片 / Logo
- 按分类筛选：海外仓 / 配送 / 清关 / 品牌
- 素材卡片：缩略图 + 名称 + 时长/尺寸
- 点击可预览（视频播放 / 图片放大）
- 「使用此素材」按钮 → 关联到当前编辑内容

**4. 数据库表**
```sql
CREATE TABLE IF NOT EXISTS assets (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    filepath TEXT NOT NULL,
    file_type TEXT NOT NULL,  -- 'video' / 'image'
    category TEXT,            -- 'warehouse' / 'delivery' / 'customs' / 'logo'
    duration INTEGER,         -- 视频时长（秒），图片为 NULL
    size INTEGER,             -- 文件大小（字节）
    thumbnail TEXT,           -- 缩略图路径
    created_at TEXT DEFAULT (datetime('now'))
);
```

### 验收标准
- [ ] 素材库页面可浏览所有视频/图片
- [ ] 按类型和分类筛选正常
- [ ] 视频可播放预览
- [ ] 图片可放大查看
- [ ] 可将素材关联到内容

## 三、小红书预览图片修复

### 需求
1. 小红书预览图片点击无反应
2. 图片太小看不清楚

### 实现方案

**1. 图片点击放大（Lightbox）**
```javascript
// 点击预览图片 → 全屏查看
function openLightbox(imageSrc) {
    const overlay = document.createElement('div');
    overlay.className = 'lightbox-overlay';
    overlay.innerHTML = `
        <div class="lightbox-content">
            <img src="${imageSrc}" alt="预览图片"/>
            <button class="lightbox-close" onclick="this.parentElement.parentElement.remove()">✕</button>
        </div>
    `;
    overlay.onclick = (e) => {
        if (e.target === overlay) overlay.remove();
    };
    document.body.appendChild(overlay);
}
```


```javascript
// 渲染小红书预览时，图片可点击
function renderXhsPreview(content, attachments) {
    const images = attachments.filter(a => a.type === 'image');
    
    return `
        <div class="xhs-preview-card">
            <div class="preview-header">
                <div class="user-info">
                    <div class="avatar">🐃</div>
                    <div class="name">BUFFALO 南非物流</div>
                </div>
            </div>
            
            ${images.length > 0 ? `
                <div class="preview-images">
                    ${images.map(img => `
                        <img src="${img.url}" 
                             onclick="openLightbox('${img.url}')"
                             alt="预览图片"/>
                    `).join('')}
                </div>
            ` : ''}
            
            <div class="preview-content">
                <h3>${content.title}</h3>
                <p>${content.body}</p>
                <div class="tags">
                    ${(content.hashtags || []).map(tag => `<span>#${tag}</span>`).join('')}
                </div>
            </div>
            
            <div class="preview-actions">
                <span>❤️ 点赞</span>
                <span>⭐ 收藏</span>
                <span>💬 评论</span>
            </div>
        </div>
    `;
}
```
