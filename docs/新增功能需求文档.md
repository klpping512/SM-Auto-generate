## 设计原则

1. **官方 API 优先**：Facebook/Twitter/Reddit 用官方 API
2. **无 API 则 RPA**：小红书/抖音用 Playwright 浏览器自动化
3. **Cookie 登录态**：首次扫码登录，保存 Cookie，不存密码
4. **人工审核**：AI 生成 → 人工确认 → 一键发布
5. **全流程日志**：异常告警、状态追踪

## 功能二：扫码登录界面

### 需求
小白同事不知道怎么连接社媒账号，需要可视化的扫码登录引导。

### 架构设计

```
用户点击「连接账号」
    ↓
弹出连接向导弹窗
    ↓
┌─────────────────────────────────────────┐
│  步骤 1：准备                            │
│  - 提示用户准备手机/账号                  │
│  - 显示操作说明                          │
├─────────────────────────────────────────┤
│  步骤 2：扫码/登录                       │
│  - 调用后端 API 启动 Playwright           │
│  - 弹出浏览器窗口让用户扫码              │
│  - 前端轮询登录状态                      │
├─────────────────────────────────────────┤
│  步骤 3：确认                            │
│  - 显示登录成功/失败                      │
│  - 保存 Cookie 到数据库                  │
└─────────────────────────────────────────┘
```

### 实现步骤

1. **后端 API：启动登录流程**
   ```python
   # app.py
   @app.post("/api/connect/{platform}/login")
   async def start_login(platform: str):
       """启动扫码登录流程"""
       adapter = adapters.get(platform)
       if not adapter:
           raise HTTPException(404, f"平台 {platform} 不支持")
       
       if adapter.CREDENTIAL_KIND != "cookie":
           return {"method": "token", "message": "请在设置页面填入 API Token"}
       
       # 启动 Playwright（非 headless，让用户看到浏览器）
       # 返回 session_id 供前端轮询
       session_id = str(uuid4())
       
       # 后台任务：打开浏览器，等待用户扫码
       asyncio.create_task(
           run_login_flow(session_id, platform, adapter)
       )
       
       return {"session_id": session_id, "status": "waiting"}
   ```

2. **后端：Playwright 登录流程**
   ```python
   async def run_login_flow(session_id: str, platform: str, adapter):
       """打开浏览器让用户扫码"""
       from playwright.async_api import async_playwright
       
       login_sessions[session_id] = {"status": "waiting", "platform": platform}
       
       try:
           async with async_playwright() as p:
               # 非 headless，让用户看到浏览器
               browser = await p.chromium.launch(headless=False)
               context = await browser.new_context()
               page = await context.new_page()
               
               await page.goto(adapter.login_url)
               
               # 等待用户登录（检测登录成功的选择器）
               try:
                   await page.wait_for_selector(
                       adapter._logged_in_selector(),
                       timeout=120000  # 2分钟超时
                   )
                   # 登录成功，保存 Cookie
                   cookies = await context.cookies()
                   login_sessions[session_id] = {
                       "status": "success",
                       "cookies": cookies
                   }
               except Exception:
                   login_sessions[session_id] = {"status": "timeout"}
               
               await browser.close()
               
       except Exception as e:
           login_sessions[session_id] = {"status": "error", "error": str(e)}
   ```

3. **后端 API：查询登录状态**

   ```python
   @app.get("/api/connect/{platform}/status/{session_id}")
   async def login_status(platform: str, session_id: str):
   ```

## 功能四：发布时添加图片/视频

### 需求
当前只能发布纯文字，需要支持上传图片/视频，与文案一起发布。

### 架构设计

```
用户上传图片/视频
    ↓
保存到本地 uploads/ 目录
    ↓
记录文件路径到数据库
    ↓
提交队列时关联附件
    ↓
发布时调用 adapter.publish(images=[...], video=...)
    ↓
adapter 内部处理：
  - RPA 平台：Playwright 上传文件
  - API 平台：multipart/form-data 上传
```

### 实现步骤

1. **文件上传 API**
   ```python
   # app.py
   @app.post("/api/upload")
   async def upload_file(file: UploadFile = File(...)):
       # 验证文件类型
       allowed_image = ['image/jpeg', 'image/png', 'image/gif', 'image/webp']
       allowed_video = ['video/mp4', 'video/quicktime', 'video/webm']
       
       if file.content_type not in allowed_image + allowed_video:
           raise HTTPException(400, "不支持的文件类型")
       
       # 验证文件大小
       content = await file.read()
       max_size = 50 * 1024 * 1024  # 50MB
       if len(content) > max_size:
           raise HTTPException(400, "文件过大（最大 50MB）")
       
       # 保存文件
       file_type = 'image' if file.content_type.startswith('image') else 'video'
       ext = file.filename.split('.')[-1]
       filename = f"{uuid4().hex}.{ext}"
       filepath = f"uploads/{file_type}/{filename}"
       
       os.makedirs(os.path.dirname(filepath), exist_ok=True)
       with open(filepath, 'wb') as f:
           f.write(content)
       
       return {
           'url': f'/static/{filepath}',
           'path': filepath,
           'type': file_type,
           'filename': file.filename,
           'size': len(content)
       }
   ```

   ```javascript
   let attachments = [];
   
   async function handleFileUpload(files) {
     for (const file of files) {
       const formData = new FormData();
       formData.append('file', file);
       
       try {
         const resp = await apiFetch('/api/upload', {
           method: 'POST',
           body: formData
         });
         const data = await resp.json();
         
         attachments.push(data);
         renderAttachments();
         showToast(`已上传：${file.name}`);
       } catch (e) {
         showToast(`上传失败：${file.name}`, 'error');
       }
     }

     const list = document.getElementById('attachmentList');
     list.innerHTML = attachments.map((a, i) => {
       if (a.type === 'image') {

               style="position:absolute;top:-6px;right:-6px;width:20px;height:20px;border-radius:50%;background:#EF4444;color:white;border:none;font-size:12px;cursor:pointer;">×</button>

         return `
           <div style="position:relative;padding:8px;background:var(--bg-secondary);border-radius:8px;font-size:11px;">
   ```

   ```javascript
   async function submitToQueue() {
   ```

   ```python
       attachments = json.loads(item.get('attachments', '[]'))
       images = [a['path'] for a in attachments if a['type'] == 'image']
       video = next((a['path'] for a in attachments if a['type'] == 'video'), None)
       
       result = await adapter.publish(
           platform=item['platform'],
           title=item['title'],
           content=item['body'],
           tags=item.get('hashtags', []),
           images=images if images else None,
           video=video
       )
       
       return result
   ```

## 技术要点

1. **Playwright RPA**
   - 登录时用 `headless=False`（让用户看到浏览器）
   - 发布时用 `headless=True`（后台执行）
   - Cookie 通过 `context.cookies()` 获取，`context.add_cookies()` 恢复

2. **文件上传安全**
   - 验证 MIME type + 扩展名
   - 文件名随机化（uuid）
   - 限制大小（图片 10MB，视频 50MB）

3. **多轮对话**
   - 前端维护 `chatHistory` 数组
   - 后端接收 `messages` 数组传给 MiMo
   - 快捷指令直接拼 prompt，不走多轮
