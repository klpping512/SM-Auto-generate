## 功能一：应用图标（Dock 栏 Logo）

### 需求
macOS Dock 栏显示默认的浏览器/终端图标，没有品牌识别度。需要添加 SA-LogiFlow 的应用图标。

### 方案
由于这是 Web 应用（FastAPI + HTML），有两种路径：

**路径 A：PWA 图标（推荐，立即可做）**
- 在 HTML 中添加 favicon 和 Apple Touch Icon
- 用户可以通过 Safari「添加到 Dock」变成伪原生应用

**路径 B：Electron/Tauri 打包（后续考虑）**
- 打包成真正的桌面应用
- 工作量大，暂不做

### 实现步骤（路径 A）

1. **生成图标文件**
   - 创建一个简单的 SVG 图标（卡车 + LogiFlow 文字）
   - 转换为多尺寸 PNG：16x16, 32x32, 180x180, 512x512
   - 生成 `favicon.ico`

2. **添加到项目**
   ```
   static/
     icons/
       favicon.ico
       icon-16.png
       icon-32.png
       icon-180.png    (Apple Touch Icon)
       icon-512.png    (PWA manifest)
   ```

3. **修改所有 HTML 的 `<head>`**
   ```html
   <link rel="icon" type="image/x-icon" href="/static/icons/favicon.ico"/>
   <link rel="apple-touch-icon" href="/static/icons/icon-180.png"/>
   <meta name="theme-color" content="#6366f1"/>
   ```

4. **创建 PWA manifest（可选）**
   ```json
   // static/manifest.json
   {
     "name": "SA-LogiFlow",
     "short_name": "LogiFlow",
     "start_url": "/",
     "display": "standalone",
     "background_color": "#0a0a0f",
     "theme_color": "#6366f1",
     "icons": [
       {"src": "/static/icons/icon-512.png", "sizes": "512x512", "type": "image/png"}
     ]
   }
   ```
   在 HTML 中添加：`<link rel="manifest" href="/static/manifest.json"/>`

5. **FastAPI 路由**
   在 `app.py` 中添加静态文件路由（如果还没有的话）

### 验收标准
- [ ] 浏览器标签页显示自定义图标
- [ ] Safari 地址栏显示图标
- [ ] 「添加到 Dock」后显示自定义图标

## 功能二：社媒平台扫码登录界面

### 需求
当前连接社媒账号只有文字说明，小白同事不知道怎么操作。需要一个可视化的扫码登录引导界面。

### 用户故事
作为运营小白，我希望：
1. 点击「连接账号」后看到清晰的步骤指引
2. 看到二维码扫描的位置示意图
3. 有实时状态反馈（连接中/成功/失败）
4. 失败时有重试和常见问题解答

### 方案

**核心思路**：每个平台的登录方式不同，需要分别处理：

| 平台 | 登录方式 | 实现难度 |
|------|---------|---------|
| 小红书 | Cookie 登录（慧媒 CLI） | 中 |
| 抖音 | Cookie 登录（慧媒 CLI） | 中 |
| Facebook | OAuth 2.0（Graph API） | 低 |
| Twitter | OAuth 1.0a（API v2） | 中 |
| Reddit | OAuth 2.0（PRAW） | 低 |

**推荐方案**：分两层实现

**第一层：引导式 UI（立即可做）**
- 每个平台一个「连接向导」弹窗
- 分步骤展示操作说明（带截图/示意图）
- 调用后端 API 触发实际连接

**第二层：真实 OAuth 流程（后续）**
- Facebook/Reddit 用标准 OAuth
- 小红书/抖音用慧媒 CLI 辅助

### 实现步骤

1. **创建连接向导组件** `static/components/connect-wizard.html`
   ```html

       <div class="step">2. 扫码</div>
       <div class="step">3. 确认</div>
     </div>
     <div class="step-content">
       <!-- 动态内容 -->
     </div>
   </div>
   ```

2. **各平台连接流程定义**

   - 「连接账号」按钮触发向导弹窗

5. **慧媒 CLI 集成**
   ```python
   # 在 publisher.py 中添加
   async def init_huimei_login(platform: str) -> dict:
       """调用 huimei login 获取扫码 URL"""
       proc = await asyncio.create_subprocess_exec(
           HUIMEI_BIN, 'login', platform,
           stdout=asyncio.subprocess.PIPE,
           stderr=asyncio.subprocess.PIPE
       )
       stdout, stderr = await proc.communicate()
       return {'url': stdout.decode().strip(), 'status': 'pending'}
   ```

## 功能四：发布时添加图片/视频

### 需求
当前只能发布纯文字，需要支持：
1. 上传图片/视频到内容
2. 预览多媒体效果
3. 与文案一起发布到各平台

### 方案

**存储方案**：
- 本地存储：`static/uploads/` 目录
- 数据库记录：文件路径、关联内容

**前端改造**：
- 编辑器添加「附件」区域
- 拖拽上传 + 点击上传
- 图片预览 + 视频缩略图

**后端改造**：
- 文件上传 API
- 与队列关联

**发布集成**：
- 慧媒 CLI 支持 `--images` 和 `--video` 参数
- 各平台 adapter 需要处理多媒体

### 实现步骤

1. **文件上传 API**
   ```python
   # app.py
   @app.post("/api/upload")
   async def upload_file(file: UploadFile):
       # 验证文件类型
       allowed_types = {
           'image': ['image/jpeg', 'image/png', 'image/gif', 'image/webp'],
           'video': ['video/mp4', 'video/quicktime', 'video/webm']
       }
       
       # 验证文件大小
       max_size = 50 * 1024 * 1024  # 50MB
       
       # 保存文件
       file_type = 'image' if file.content_type.startswith('image') else 'video'
       filename = f"{uuid4().hex}_{file.filename}"
       filepath = f"uploads/{file_type}/{filename}"
       
       os.makedirs(os.path.dirname(filepath), exist_ok=True)
       with open(filepath, 'wb') as f:
           content = await file.read()
           f.write(content)
       
       # 存数据库
       db.save_asset(filepath, file_type, file.filename)
       
       return {
           'url': f'/static/{filepath}',
           'type': file_type,
           'filename': file.filename
       }
   ```

2. **数据库表**
   ```sql
   CREATE TABLE IF NOT EXISTS assets (
       id INTEGER PRIMARY KEY AUTOINCREMENT,
   ```

## 技术注意事项

1. **文件上传安全**
   - 验证文件类型（MIME type + 扩展名）
   - 限制文件大小（图片 10MB，视频 50MB）
   - 文件名随机化（防路径遍历）

2. **SSE 流式响应**
   - FastAPI 用 `StreamingResponse`
   - 前端用 `ReadableStream` 或 `EventSource`

3. **慧媒 CLI 集成**
   - `huimei login` 会打开浏览器，需要用户手动操作
   - 可以用 `--qrcode` 参数获取二维码图片

4. **PWA 兼容性**
   - macOS Safari 支持「添加到 Dock」
   - 需要 HTTPS（本地开发用 localhost 可以）
