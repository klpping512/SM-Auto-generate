## 问题清单

### 1. 导入失败
**现象**: 素材库扫描导入功能无法正常工作  
**原因**: 
- 导入目录 `static/assets/import/` 可能为空
- 文件格式不匹配（HEVC/MOV格式兼容性问题）
- 错误信息未明确反馈给用户

### 2. 分类不准确
**现象**: 工作人员工作视频被分类到「其他」  
**原因**: 
- 当前分类只有5个：`warehouse`、`delivery`、`customs`、`brand`、`other`
- 缺少「工作人员」分类
- 导入时使用全局分类参数，无法根据文件名/目录智能判断

### 3. 分类体系不完善
**当前分类**:
```python
CATEGORIES = {"warehouse", "delivery", "customs", "brand", "other"}
```

**问题**:
- 没有「工作人员」分类
- 没有「设备设施」分类
- 没有「客户案例」分类
- 「其他」分类过于笼统

## 改进方案

### Phase 1: 扩展分类体系

**新增分类**:
```python
CATEGORIES = {
    "warehouse",      # 仓库/海外仓
    "delivery",       # 配送/物流
    "customs",        # 清关/海关
    "brand",          # 品牌/Logo
    "staff",          # 工作人员 ✨新增
    "facility",       # 设备设施 ✨新增
    "customer",       # 客户案例 ✨新增
    "other"           # 其他
}
```

**分类说明**:
| 分类 | 说明 | 示例 |
|------|------|------|
| warehouse | 仓库全景、货架、分拣线 | 海外仓展示视频 |
| delivery | 配送车辆、快递员、派送过程 | 配送路线视频 |
| customs | 清关文件、海关检查 | 清关流程视频 |
| brand | Logo、品牌宣传、公司介绍 | 品牌宣传片 |
| staff | 工作人员、团队、培训 | 员工工作视频 ✨ |
| facility | 设备、叉车、传送带 | 设备操作视频 |
| customer | 客户访谈、案例展示 | 客户好评视频 |
| other | 无法归类 | - |

### Phase 2: 智能分类推荐

**根据文件名/目录名自动判断分类**:

```python
CATEGORY_KEYWORDS = {
    "warehouse": ["仓库", "海外仓", "warehouse", "存储", "货架", "分拣"],
    "delivery": ["配送", "delivery", "快递", "派送", "物流车", "运输"],
    "customs": ["清关", "customs", "海关", "报关", "关税"],
    "brand": ["品牌", "brand", "logo", "宣传", "公司"],
    "staff": ["员工", "staff", "工作", "团队", "培训", "操作员", "人员"],  # ✨新增
    "facility": ["设备", "facility", "叉车", "传送带", "机器"],
    "customer": ["客户", "customer", "案例", "好评", "反馈"],
}

def guess_category(filename: str) -> str:
    """根据文件名猜测分类"""
    name_lower = filename.lower()
    for category, keywords in CATEGORY_KEYWORDS.items():
        for keyword in keywords:
            if keyword in name_lower:
                return category
    return "other"
```

2. 点击「扫描导入目录」
3. 视频自动归类为「工作人员」
4. 素材库显示正确分类

### 分类准确率标准
- 文件名包含关键词：准确率 90%+
- 子目录分类：准确率 100%
- 无法识别：归类为「其他」
