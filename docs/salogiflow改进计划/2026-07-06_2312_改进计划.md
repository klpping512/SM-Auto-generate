# SA-LogiFlow 2026-07-05 改进计划

## 问题清单

### 1. 页面切换内容丢失
**现象**: AI对话生成内容后，切换到其他页面再切回来，内容被清空  
**原因**: 页面状态未持久化，依赖内存变量  
**修复方案**: 
- 使用 localStorage 保存当前对话和生成结果
- 页面加载时自动恢复上次状态

### 2. 视频推送到编辑器的交互优化
**现象**: AI对话生成视频后推送到编辑器，预览不正确  
**期望**:
- 右侧预览器 → 显示视频播放器
- 左侧编辑器 → 只显示文案内容
- 一起发布到抖音账号

**修复方案**:
- editor.html 检测到抖音内容时，右侧切换为视频预览模式
- 左侧只显示标题、正文、话题标签
- 保留「发布到抖音」按钮

### 3. 平台选择默认值
**现象**: AI对话的平台选择默认是小红书  
**期望**: 让用户自己选择，不设默认值  
**修复方案**: 
- 移除 `k==='xiaohongshu'?'active':''` 逻辑
- 初始状态无选中，用户必须主动选择

### 4. 审核中心功能合并
**现象**: 审核中心和发布队列功能重复  
**期望**: 合并为一个页面  
**修复方案**:
- 删除 review.html
- 在 queue.html 中增加「待审核」筛选标签
- 审核操作（通过/拒绝）直接在队列页面完成

### 5. 小红书发布失败排查 ⚠️
**错误信息**:
```
ID:9 | xiaohongshu | queued | 重试中 (1/3): cookie/登录失效，请重新登录小红书账号
ID:8 | xiaohongshu | failed | 小红书必须配图，images 不能为空
```

**根因分析**:

#### 问题A: cookie/登录失效
- 小红书适配器使用 Playwright RPA 模式
- 需要有效的 cookie 才能登录创作平台
- 当前账号 cookie 可能已过期

**修复方案**:
1. 在账号管理页面增加「测试连接」功能
2. 点击后自动检查 cookie 有效性
3. 如果失效，提示用户重新登录获取 cookie
4. cookie 存储在数据库 accounts 表的 credentials 字段

#### 问题B: images 不能为空
- 小红书必须配图才能发布
- 提交到队列时如果没有图片，自动生成小红书图文卡片
- 但当前逻辑可能没有正确触发

**修复方案**:
1. 在 editor.html 提交时检查平台要求
2. 小红书平台自动调用 `/api/xhs/render` 生成图片
3. 确保 attachments 中包含 type=image 的记录

## 技术细节

### 小红书 cookie 获取方法
1. 打开浏览器，登录 https://creator.xiaohongshu.com
2. 打开开发者工具 → Application → Cookies
3. 复制所有 cookie 值
4. 格式: `key1=value1; key2=value2; ...`
5. 保存到账号管理的 credentials 字段

### localStorage 键名规范
- `chat_sessions`: AI对话历史
- `editor_draft`: 编辑器草稿
- `selected_platform`: 选中的平台

## 验证标准

### 小红书发布成功标准
1. 账号管理页面显示「连接正常」
2. 提交到队列时自动渲染图片
3. 点击发布后状态变为「已发布」
4. 小红书创作平台能看到新笔记

### 视频推送成功标准
1. AI对话生成抖音内容后，点击「发送到编辑器」
2. 编辑器右侧显示视频播放器
3. 左侧显示文案内容
4. 点击「发布到抖音」成功提交
